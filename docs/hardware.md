## 可用内存法则

- 系统 + Cursor/IDE + 浏览器预留约 **10–12 GB**
- 模型权重 + KV cache 实用预算约 **34–38 GB**
- 同时只加载 **一个** ≥18GB 的大模型
- 「高质量」档优先提高量化精度，并**主动限制上下文**，不要硬开官方 256K

## 甜点与禁区

- **甜点**：30–35B MoE（约 3B 激活）Q4–Q6；27B 稠密 Q6–Q8
- **不推荐常态**：70B+ 稠密（权重与上下文互相挤压，Agent 体验差）
